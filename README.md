# Ecosistema COD - Centro de Operaciones Digitales 👔
Este es el núcleo de automatización y gestión empresarial de Juan.

## Estructura del Proyecto
- **/automatizaciones**: Scripts y tareas programadas que corren 24/7.
- **/documentacion**: Manuales, estrategias y notas ejecutivas.
- **/proyectos**: Desarrollo de nuevas herramientas y servicios.
- **/logs**: Registro de actividad del sistema.

## Estado del Sistema
- **Servidor:** AWS Lightsail (Ubuntu 24.04 LTS)
- **Asistente:** Ramon (OpenClaw v2026.5.12)
- **Frecuencia de Check:** Cada 30 minutos.
